# TripEZGo language website

GitHub Pages shell repository. Source content is maintained in [TripEZGo/tripezgo.github.io](https://github.com/TripEZGo/tripezgo.github.io).

The `DEPLOY_LANG` Actions variable selects the language; `SOURCE_REPOSITORY` selects the source repository. Run the Pages workflow after the language-site generator is published to the source main branch.
